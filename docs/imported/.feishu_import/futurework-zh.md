# 未来工作（Future work）

`any-sync` 的未来发展聚焦三个方向：

1. **全球 P2P 中继（Global Peer-to-Peer Relays）**：通过解决连接挑战，实现互联网上的无缝直接同步，确保在所有场景下都能进行可靠的点对点通信。

2. **多提供商支持（Multi-Provider Support）**：允许用户连接多个同步提供商，引入灵活性与韧性，减少对单一提供商的依赖，同时提升性能与可靠性。

3. **嵌套访问控制列表（Nested ACLs）**：实现高级的分层权限管理，赋予频道所有者对访问权限的精细控制，在每一个层级促进安全协作。
