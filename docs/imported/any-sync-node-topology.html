基础设施节点拓扑与数据流
四种节点（协调 / 同步 / 文件 / 共识）+ 客户端与频道；对照官方《Networking and Infrastructure》Node Types 一节
Client
客户端（你的设备）
轻量连接，不跑完整 DHT
subscribes for updates
订阅更新 / 推送变更
Channel
频道 / 空间
加密 DAG；成员由 ACL 决定
is managed by
由同步节点管理
Coordinator node
协调节点
拓扑与路由：分发子网配置；频道 ID → 同步节点（一致性哈希）；签署频道头
Consensus node
共识节点
验证更新的 ACL（RAFT）；以网络密钥签名后传播回同步节点
Sync node
同步节点
存储与交换频道数据；常在线对等体；每个频道多个副本
File node
文件节点
基于 IPLD 存储/检索二进制文件；授权后供应数据
交互路径：客户端 → 协调节点（获取节点/副本地址）→ 同步节点（订阅更新）；客户端 → 文件节点（检索文件）；同步节点 → 共识节点（提交 ACL 变更）→ 验证后回传。图中内容为代码绘制的可编辑示意，修改源码即可更新。
