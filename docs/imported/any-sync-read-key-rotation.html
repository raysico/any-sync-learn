读取密钥（Read Key）轮换流程示意图
新增/移除成员时轮换对称读取密钥，并逐条追加 ACL 记录；对照官方《Access control and Encryption》ACL and Encryption 一节
Sym Obj
对称对象
按对象 ID 进行路径派生（Path derivation based on Id）
➜
Read Key M
读取密钥（对称）
AES
加密空间/对象/变更的对称密钥（当前版本）
➜Encrypts previous key
（加密旧密钥，形成加密链）
READ KEY ROTATION
读取密钥轮换
新密钥 M+1 加密旧密钥 M；授权成员可凭新密钥解密全部历史
➜
Read Key M+1
读取密钥（对称，新）
AES
轮换后的新读取密钥
ACL Record N
当前状态
Read Key M 加密给：
用户 A 公钥用户 B 公钥
ACL Record N+1
移除用户 B
Read Key M+1 加密给：
用户 A 公钥用户 B 公钥
ACL Record N+2
添加用户 C
Read Key M+1 加密给：
用户 A 公钥用户 C 公钥
读图顺序：对象密钥由空间当前对称密钥（Read Key）与对象 CID 派生 → 空间密钥为每个当前成员分别加密 → 密钥轮换时新密钥加密旧密钥，形成加密链，授权成员可解密完整历史。
术语以英文原词为准；本图为代码绘制的可编辑示意，修改源码即可更新。
