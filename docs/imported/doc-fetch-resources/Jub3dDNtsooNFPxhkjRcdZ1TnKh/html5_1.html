两层哈希负载分配（Two-Layer Hashing）
第一层模哈希：频道/空间 → 分区；第二层一致性哈希：分区 → 节点环；对照官方《Networking and Infrastructure》Scalability 一节
第一层 · 模哈希（Modular Hashing）
h(S1) % p = p1
Space 1➜Partition 1➜Hash 1
Space 2➜Partition 2➜Hash 2
Space 3➜Partition 3➜Hash 3
RF = 2（副本因子：每个分区由 2 个节点承载）
第二层 · 一致性哈希（Consistent Hashing）
节点加入/离开时，分区在环上平滑重排（reshard）；节点过载时由附加启发式重新分配分区。
读图顺序：频道 ID →（模哈希）→ 分区 →（一致性哈希）→ 环上最近节点；副本因子 RF=2 保证冗余。本图为代码绘制的可编辑示意，修改源码即可更新。
