保险库（Vault）密钥派生示意图
由 BIP-39 助记词离线派生全部密钥；对照官方《Access control and Encryption》Vault Inception 一节
A · 助记词派生（SLIP10）
Seed Phrase
助记词（BIP-39，12 词）
BIP-39
全程离线；私钥永不离开设备
➜SLIP10
Master Key
主密钥
Ed25519
签名/认证 ACL 记录中的身份；必要时恢复身份
➜SLIP10
Identity Key
身份密钥
Ed25519
保险库所有者的公钥身份；在 ACL 记录中签署空间头
➜SLIP10
Ethereum Key
以太坊密钥
ECDSA
签署以太坊交易，供 Any 命名系统（ANS）按需使用
B · 随机派生（与助记词无关）
Random Function
随机函数
Vault 创建时生成
➜
Device Key (Peer Id)
设备密钥 / 对等密钥
Ed25519
作为托管网络中的 Peer ID；负责 P2P 握手（DH 与 Anytype 握手）
C · 由身份密钥进一步派生
Identity Key
身份密钥
Ed25519
（上一区块所派生）
➜HASH(公钥)
Replication Key
复制密钥
一致性哈希：决定哪些同步节点承载该空间（负载均衡/分区）
➜SLIP21
Account Metadata Key
账户元数据密钥
AES
加密 ACL 记录中的身份元数据
术语以英文原词为准；本图为代码绘制的可编辑示意，修改源码即可更新。
